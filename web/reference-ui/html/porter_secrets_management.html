Envelope Encryption & MicroVM Safety Guarantee

Porter prevents credential exfiltration by design. Decrypted payload data never touches host SSDs, Swap partitions, or Docker layers. Secrets are held ephemerally in volatile host ring-0 memory and passed over an isolated UNIX socket directly into the Firecracker jailer root environment.

01 · KMS HSMS Envelope Key Unseal 256-bit AES GCM master key unwrapped within FIPS 140-2 Level 3 hardware.
02 · Jailer TAP In-Memory Pipe Streamed through unidirectional anonymous mmap boundary without disk IO.
03 · MicroVM Boot RAM Resident Kernel receives payload at init; immediately locked via mlock().
04 · Shutdown / Purge Zeroed on Exit MicroVM memory scrubbed by KVM hypervisor on instance teardown.
