What does Add Replica do?
Immediate capacity

Adds MicroVMs to this deployment now. Autoscaling is the reusable min/max policy that decides when to do that automatically.

Project → Deployment → Replica

Project — logical group
Deployment — immutable build (v2.4.0)

Danger Zone

Deployment vs Replica
Deployment = immutable build artifact (v2.4.0, v2.5.0-rc1). Replica = running MicroVM serving that build.
→ 1 deployment can have 1..N replicas. → Replica-1 is primary (always on).
