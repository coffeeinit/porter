## Usage

```bash
export PORTER_URL=https://porter.example.com
export PORTER_TOKEN=ptr_admin_...

porter status
porter nodes
porter projects
porter deploy <project-id> <app-name> <image> [replicas]
porter logs <vm-id>
porter scale <app-id> 3
porter rollback <app-id>
porter join-token
porter backup
```
